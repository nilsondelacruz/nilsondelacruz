## 📌 Featured Projects

### 🔍 HR Attrition Analysis — IBM Dataset

> Identifying what makes employees leave — and what keeps them.

```
Dataset  : IBM HR Analytics (1,470 employees)
Tools    : Python · Power BI · Excel
Focus    : Predictive insights + business recommendations
```

**Key findings:**

| 🔎 Driver | 📊 Impact |
|:---|:---|
| **Overtime** | Employees doing overtime have **2.93× higher** attrition risk |
| **Salary** | Turnover spikes significantly below **S/ 5,000/month** |
| **Department** | R&D has the **highest attrition concentration** |
| **Job Level** | Entry-level roles show the most instability |

**Recommendations delivered:** reduce overtime exposure · review salary bands · targeted retention by department
